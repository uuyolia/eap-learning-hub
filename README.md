原第 1 期五篇主题文章、16 词、15 句型保留在 index.html，增强功能使用 app.js 与 app.css。无 JavaScript 时仍可阅读原内容。

## 学习功能

- 生词、熟词分类；熟词不进入常规复习，可重新标记为生词。
- 间隔为 1、2、4、7、15、30 天；忘记则 10 分钟后复习。这是固定间隔算法，不是个体遗忘曲线测量。到期提醒仅在打开网页时显示。
- 访客记录保存在当前浏览器；邮箱登录并验证后，学习记录同步到账号云空间。保留旧 eap_saved_v2、eap_note_v2，支持下载和合并导入旧备份。
- Speaking：MediaRecorder 录音，动态检测 MP4/WebM/OGG，试听和下载；录音不上传、不跨刷新保存。可选已有音频试听。网页录音需 HTTPS 与麦克风授权。
- SpeechRecognition 在支持时提供实时英文转写；浏览器可能调用在线服务。iPhone 可用系统键盘听写替代。选入音频不自动转写。
- 反馈仅统计词数及连接表达，不能判断语法准确性、发音、语调或流利度。专业语音评测需另接服务、后端与密钥；不得把服务密钥放进静态网页。
- 新闻按日期归档，一期五篇，逐篇翻页。素材库自动收录公共案例，另可本地写笔记、按主题/日期/关键词筛选和新增每日素材。
- assets/topic.svg 为本站原创示意插图，非现场照片，无第三方新闻照片授权依赖。

## SCW1 课程主题与模拟训练

新增 exam-core.js（十主题、50 道自编模拟题、透明文本统计和自评权重）、exam.js（模拟流程、录音、结果报告）。课程主题来自登录后的 EAP047 课本 Units 1–10；SCW1 流程与六维权重参考正式任务说明，练习题并非官方真题。Part1 二选一、准备60秒、作答120秒；Part2 从不同主题中二选一、四类追问共240秒。计时按墙上时钟，后台不暂停。每题录音按浏览器支持格式采集，不上传，刷新后丢失，需下载。

评分有两套，严禁混称正式考试预测分：自动文本训练覆盖分对每题计20分，填写10、达到长度阈值4、检测原因表达3、检测例子表达3；五题最多100分。它是可被关键词影响的结构统计，不判断语义切题、事实和语言正确性；没有转写时仅表示文本待补全。正式维度自评需人工回听后填满Part1内容20、Part2内容20、流利度衔接15、词汇15、语法15、发音15才给总分。没有接入专业发音/音频评分服务，没有自动音频转写，绝不从文字推测语调。用户可复制完整评估请求和下载录音，在能分析音频的服务中进一步评估。

新闻与公共素材新增 courseTopics 数组，仅使用十个英文主题ID；其关联是本站编辑归类，不是官方对报道的认证。两期 NASA 专题已移除，其余每日简报及配套学习数据保留。未来新闻优先匹配课程主题，每期尽量至少3个主题、同一主题不超过2条。

## 首页导航、每日词汇与文章摘录

默认入口 #home；新闻、单词、句型、复习、口语、模拟考试、素材和记录分屏展示，保留原有深链接。无脚本时仍可浏览基础内容。screens.js 只控制栏目，不删除原内容。

每日 data/language.json（version:1）维护累计 words 与 phrases：id、term、meaning、example、issueId、date、articleTitle、articleIndex、sourceUrl、courseTopics；可含 ipa、sourceText、sourceKind。已为两期简报补20词汇/词组和10句型。每项从正文或配套表达提取，保留来源语境，不将配套表达误称为新闻原句。

在新闻英文内选择文字，底部出现加入单词/句型按钮。确认释义与语境后，写入浏览器 eap_personal_language_v1，不上传公共仓库。支持手动添加；按词条规范化合并，保留不同来源语境，熟词不被自动重置。自选单词进入现有复习队列（既有熟词除外）。词库/句型库可按日期、基础/新闻/个人、关键词筛选，每页12项。

导出改为version:4，含 language 个人词句库；仍可导入旧v3备份，导入采用合并。v4备份保留旧收藏、复习、笔记和案例。无法保存时提示，未知释义留为待补充，不伪造翻译或音标。

后续浏览器验证与打开EAP内容使用Chrome，用户未要求改默认系统浏览器。

## 新闻 Part 2 练习与底部分页

news-practice.js 按文章内容选择主题练习，默认收起，点击“练习这一题 · Part 2”后在新闻内展开四类追问、多角度思路和英文表达，不再跳到口语草稿。每篇更新后重置收起状态，保留文章选词功能。第四问优先沿用新闻讨论题。所有追问为本站模拟，非官方题库。

可在文章 JSON 中提供 part2Practice.questions（恰好4项），每项含 question、zh、directions（字符串数组）、expressions（{en,zh}数组），以覆盖通用主题模板。新问题应贴合新闻及SCW1 Part2四类动作词。

单词与句型库分页控件位于各自列表之后。翻页后返回本栏目顶部，便于从新页第一项开始阅读。


## 每日学习与口语成长记录
首页新增约 15 分钟的今日学习：标记一篇新闻已读、复习最多五个到期单词、保存一道口语回答。没有到期词时该步显示无需复习，可自选未分类词。每日记录按设备本地日期计算。

新闻追问、课程主题及模拟考试可保存英文回答；同一题可重答并比较第一次与最新转写，每次提供两项基于文本结构线索的练习建议及英文表达。模拟考试反复分析会更新该轮对应题目，不重复累计。录音仍须另行下载，未接入发音或语调自动评分。

话题覆盖仅统计最近七个本地自然日保存过英文回答的主题，主题按钮可直接开始练习；练习较少不代表能力较差。新版 v5 备份包含口语历史、今日进度和草稿，继续兼容 v3/v4 导入。访客记录只存在当前浏览器；邮箱账号验证后可同步文字记录。


## 分享、档案与语境查询
公开网址可以分享；学习记录不包含在网址中。邮箱账号提供跨设备文字记录同步，不同账号由服务端规则隔离。同一浏览器旧版档案仍保留，通过 EAPStorage 隔离；旧版未命名空间数据继续属于“我的学习”，不会删除。邮箱登录后需主动选择导入旧版档案；访客档案不等于云账号。导入/导出只针对当前账号或档案。

追问示范中文已改为忠实翻译；补充方向和表达提供新角度。选词优先匹配 data/context-glosses.json、当前文章的 language 条目及原文括注；未命中时通过 MyMemory 查询候选词义及句子翻译，需要确认。Free Dictionary API 提供可获取的词典音标并标来源和许可，短词组展示分词音标，长句不拼造音标。服务可能限额、缺词或不可用，允许编辑和手动补充。设备英语朗读不代表专业发音评分。自动查询不使用密钥、不上传个人学习记录；外部查询仅发送选中内容和公开文章的所在句。


## 邮箱账号与跨设备同步

邮箱注册、登录、验证、密码重置已连接专用 Firebase 项目 eap-learning-hub-uuyolia。Cloud Firestore Standard 默认数据库位于新加坡 asia-southeast1，当前使用免费额度，未绑定付费套餐。cloud-config.json 仅含 Web 公开配置；服务账号、管理员凭据与访问令牌禁止提交。

已验证邮箱用户可同步六类文字记录：复习进度、收藏、素材笔记、个人词句、口语草稿、练习历史和今日进度。旧版本机记录保留，登录后在设置主动导入。录音不上传、不跨设备同步，仍需自行下载。

服务端规则只允许已验证邮箱的用户访问自己的允许列表文档，拒绝集合遍历、跨账号读写、额外字段、过期版本与客户端删除。客户端用事务递增版本，进行三方合并；同字段冲突保留两份供选择。离线先保存在当前浏览器，联网后停止录音、结束考试或输入框失焦时重试。同步后的异设备更新不会在正在练习时强行替换。

2026-11-23 已完成规则语法检查，以及真实服务的两账号/两独立客户端同步与权限测试。邮箱验证和密码重置的官方链接生成已通过；真实邮箱送达和用户手机的端到端确认仍需首次使用时检查，不能把两个测试客户端冒称两部实物手机。详见 CLOUD_SETUP.md。
